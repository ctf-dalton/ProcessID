CTF Challenge: Digital Forensics & Steganography

Category: Digital Forensics / Steganography
Difficulty: Medium

Overview

This repository contains the evidentiary material for the digital forensics challenge. Investigate the provided image asset using standard steganographic analysis techniques to extract the hidden artifact required for the incident report.

Instructions

Download the evidence file directly from this repository without altering its format or compressing it.

Utilize offline or web-based steganography tools (such as StegOnline) to inspect the image bit planes and extract embedded data.

Use your findings to answer the active question on your challenge portal.
